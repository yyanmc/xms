REM 在 VS2022 Developer Command Prompt 中执行

set XMS_ROOT=D:\Code\cpp\C++微服务架构及安全云盘项目\xms0.1.1
set BUILD_CFG=Debug
set BUILD_PLAT=Win32

REM 1. 构建基础库
msbuild %XMS_ROOT%\LXMysql\LXMysql.vcxproj /p:Configuration=%BUILD_CFG% /p:Platform=%BUILD_PLAT%
msbuild %XMS_ROOT%\xplatform\xplatfrom.vcxproj /p:Configuration=%BUILD_CFG% /p:Platform=%BUILD_PLAT%

REM 2. 构建所有服务和服务端
for %%p in (
  register_server config_server xauth_server xlog_server
  xms_gateway xms_dir_service xms_upload_service
  xms_download_service config_client register_client
) do (
  msbuild %XMS_ROOT%\%%p\%%p.vcxproj /p:Configuration=%BUILD_CFG% /p:Platform=%BUILD_PLAT%
)

运行时 DLL 清单:
- libprotobuf.dll (必须，所有服务需要)
- xplatform_d.dll (如果构建为 DLL)
- libssl.dll + libcrypto.dll (OpenSSL)

10. 常见问题排查

🔥 服务启动后闪退
可能原因:
1. DLL 缺失 → 将所有依赖 DLL 放到 exe 同目录
2. 端口被占用 → netstat -ano | findstr 20018
3. MySQL 连接失败 → 检查 MySQL 服务状态
4. hosts 解析失败 → ping xms_register_server
🔗 服务连接失败
排查步骤:
1. 确认注册中心先启动
2. 检查防火墙是否放行端口
3. 检查 hosts 文件
4. 查看控制台诊断信息
🗄️ MySQL 连接问题
排查步骤:
1. net start MySQL80 启动MySQL
2. mysql -u root -p -e "SHOW DATABASES;"
3. 检查 DAO 中的连接参数 (IP/用户/密码)
⚙️ 编译错误
常见问题:
1. LNK1104 找不到 .lib → 先构建依赖项目
2. 找不到 include 头文件 → 检查目录链接
3. Qt 相关错误 → 检查 Qt6 配置
4. protobuf 版本冲突 → 确保所有项目用同一版本
