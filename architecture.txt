一、项目概述
--------------------------------------------------------------------------------
本项目是一个基于 C++ 的分布式微服务架构安全云盘系统。采用 libevent 异步网络
框架 + Google Protobuf 序列化 + MySQL 数据库的技术栈，实现了服务注册与发现、
配置中心、用户鉴权、日志收集、文件上传/下载等核心功能，并提供 Qt 桌面客户端。

三、基础设施层 (xplatform) — 核心通信框架
--------------------------------------------------------------------------------

3.1 类继承体系

  XTask (基类)
  ├─ 属性: base_(event_base), sock_, ssl_ctx_, thread_id_
  ├─ 方法: Init() [纯虚]

  XComTask : public XTask (网络通信层)
  ├─ bufferevent 封装
  ├─ Connect() / Close() / Read() / Write() / Init()
  ├─ SetTimer() / TimerCB() 定时器
  ├─ AutoConnect() 自动重连
  └─ ReadCB() / WriteCB() / EventCB() / ConnectedCB()

  XMsgEvent : public XComTask (消息事件层)
  ├─ Protobuf 消息收发
  ├─ RecvMsg() / GetMsg() / SendMsg()
  ├─ ReadCB() 消息分发 (静态回调表 msg_callback)
  ├─ Clear() / Close()
  └─ RegCB() 注册消息类型回调

  XServiceHandle : public XMsgEvent (服务端连接处理器)
  └─ 各业务模块继承此类实现具体逻辑

  XServiceClient : public XMsgEvent (客户端连接管理器)
  ├─ SetHead() 自动填充 token/service_name
  ├─ StartConnect() 启动连接
  └─ set_login() 设置登录信息

  XLogClient : public XServiceClient (日志客户端)
  ├─ 单例模式
  ├─ 批量缓存日志，定时发送
  └─ 支持本地日志文件

  XService : public XTask (服务端基类)
  ├─ 监听端口, 接受客户端连接
  ├─ 两个线程池: listen_pool + client_pool
  ├─ CreateServiceHandle() [纯虚] 创建连接处理器
  └─ Init() / Start() / ListenCB()

3.2 线程模型

  XThread 线程类
  ├─ 每个线程拥有独立的 event_base
  ├─ socketpair(Windows) / pipe(Linux) 用于线程激活
  ├─ 任务队列 tasks_ + 互斥锁
  └─ 主循环: event_base_loop(NONBLOCK) + sleep(1ms)

  XThreadPool 线程池
  ├─ Init(count) 创建并启动 N 个线程
  ├─ Dispatch(task) 轮询分发任务
  └─ 全局: ExitAllThread() / Wait()

3.3 通信协议

  协议格式 (TCP 流):
  +------------------+------------------+------------------+
  |  头部大小(4字节)  |  Protobuf 消息头  |  消息体(可选)     |
  |    int32          |   XMsgHead       | 业务 PB 数据     |
  +------------------+------------------+------------------+

  XMsgHead 主要字段:
  ├─ msg_size: 消息体大小
  ├─ msg_type: 消息类型 (MsgType 枚举)
  ├─ token: 用户令牌
  ├─ service_name: 目标服务名称 (路由用)
  ├─ msg_id: 消息ID
  ├─ username / rolename: 用户信息
  ├─ md5: 消息体校验
  └─ offset: 文件数据偏移

3.4 安全与工具

  XSSLCtx: SSL 上下文 (OpenSSL 封装)
  ├─ InitServer(crt, key, ca) 服务端初始化
  └─ InitClient(ca) 客户端初始化

  XSSL: SSL 通信对象
  ├─ Accept() / Connect() 握手
  └─ Read() / Write() 加密通信

  XAES: AES 加解密
  ├─ 支持 128/192/256 位密钥
  └─ Encrypt() / Decrypt()

  XMutex: RAII 互斥锁封装
  XTools: 工具函数集
  ├─ XMD5 / XMD5_base64 / Base64Encode / Base64Decode
  ├─ GetDirList / GetDiskSize / GetDirSize
  ├─ XGetHostByName (域名解析)
  ├─ XGetTime / XGetSizeString
  └─ XGetPortName (端口→服务名映射)

四、基础设施微服务
--------------------------------------------------------------------------------

4.1 注册中心 (Register Server)
  ├─ 解决方案: register_server.sln → register_server.exe
  ├─ 端口: 20018
  ├─ 服务名: reg / 主机名: xms_register_server
  ├─ 职责:
  │   ├─ MSG_REGISTER_REQ: 接收服务注册
  │   ├─ MSG_GET_SERVICE_REQ: 服务发现 (按名称/全部)
  │   └─ MSG_HEART_REQ: 心跳检测
  ├─ 存储: 内存 (map<string, vector<ServiceInfo>>)
  └─ 关键类:
      ├─ XRegisterServer → XService
      └─ XRegisterHandle → XServiceHandle

4.2 配置中心 (Config Server)
  ├─ 解决方案: config_server.sln → config_server.exe
  ├─ 端口: 20019
  ├─ 服务名: config
  ├─ 职责:
  │   ├─ MSG_SAVE_CONFIG_REQ: 保存配置 (增/改)
  │   ├─ MSG_LOAD_CONFIG_REQ: 按IP+端口加载配置
  │   ├─ MSG_LOAD_ALL_CONFIG_REQ: 分页获取配置列表
  │   └─ MSG_DEL_CONFIG_REQ: 删除配置
  ├─ 存储: MySQL (config_dao → LXMysql)
  └─ 关键类:
      ├─ XConfigServer → XService
      ├─ XConfigHandle → XServiceHandle
      └─ ConfigDao (单例)

4.3 鉴权服务 (Auth Server)
  ├─ 解决方案: xauth.sln → xauth_server.exe
  ├─ 端口: 20020
  ├─ 服务名: auth
  ├─ 职责:
  │   ├─ MSG_LOGIN_REQ: 用户登录 (用户名+密码 → token)
  │   ├─ MSG_ADD_USER_REQ: 添加用户
  │   ├─ MSG_CHANGE_PASSWORD_REQ: 修改密码
  │   └─ MSG_CHECK_TOKEN_REQ: 验证令牌
  ├─ 存储: MySQL (xauth_dao → LXMysql)
  └─ 关键类:
      ├─ XAuthService → XService
      ├─ XAuthHandle → XServiceHandle
      └─ XAuthDao (单例)

4.4 日志服务 (Log Server)
  ├─ 解决方案: xlog.sln → xlog_server.exe
  ├─ 端口: 20030
  ├─ 服务名: xlog
  ├─ 职责:
  │   └─ MSG_ADD_LOG_REQ: 接收并存储日志
  ├─ 存储: MySQL (xlog_dao → LXMysql)
  └─ 关键类:
      ├─ XLogServer → XService
      ├─ XLogHandle → XServiceHandle
      └─ XLogDao

五、业务微服务
--------------------------------------------------------------------------------

5.1 API 网关 (Gateway)
  ├─ 解决方案: xms_gateway.vcxproj → xms_gateway.exe
  ├─ 端口: 20010 (API_GATEWAY_PORT)
  ├─ 服务名: gw / 主机名: xms_gateway_server
  ├─ 职责:
  │   ├─ 客户端连接入口
  │   ├─ 消息鉴权 (XAuthProxy::CheckToken)
  │   ├─ 消息路由转发 (按 service_name 分发)
  │   ├─ 负载均衡 (轮询算法)
  │   ├─ 动态服务发现 (周期性从注册中心更新)
  │   └─ 对外服务查询 (MSG_GET_OUT_SERVICE_REQ)
  └─ 关键类:
      ├─ XRouterServer → XService (监听端口)
      ├─ XRouterHandle → XServiceHandle (消息路由)
      ├─ XServiceProxy (单例, 服务代理管理器)
      │   ├─ SendMsg: 按 service_name 轮询转发
      │   └─ Main: 周期性从注册中心更新服务列表
      ├─ XServiceProxyClient → XServiceClient (代理连接)
      │   ├─ RegEvent / DelEvent: 回调管理
      │   └─ SendMsg(head, msg, ev): 带回调的消息发送
      └─ XAuthProxy → XServiceProxyClient (鉴权代理)
          └─ CheckToken: 令牌验证

5.2 目录服务 (Dir Service)
  ├─ 解决方案: xms_dir_service.vcxproj → xms_dir_service.exe
  ├─ 端口: 20300
  ├─ 服务名: dir
  ├─ 职责:
  │   ├─ GET_DIR_REQ: 获取目录文件列表
  │   ├─ DELETE_FILE_REQ: 删除文件
  │   ├─ NEW_DIR_REQ: 创建目录
  │   └─ GET_DISK_INFO_REQ: 获取磁盘空间信息
  └─ 关键类:
      ├─ XDirService → XService
      └─ XDirHandle → XServiceHandle

5.3 上传服务 (Upload Service)
  ├─ 解决方案: xms_upload_service.vcxproj → xms_upload_service.exe
  ├─ 端口: 20100
  ├─ 服务名: upload
  ├─ 职责:
  │   ├─ UPLOAD_FILE_REQ: 上传文件请求
  │   ├─ SEND_SLICE_REQ: 接收文件片
  │   ├─ UPLOAD_FILE_END_REQ: 上传完成确认
  │   └─ 支持 AES 加密文件存储
  └─ 关键类:
      ├─ XUploadServer → XService
      └─ XUploadHandle → XServiceHandle

5.4 下载服务 (Download Service)
  ├─ 解决方案: xms_download_service.vcxproj → xms_download_service.exe
  ├─ 端口: 20200
  ├─ 服务名: download
  ├─ 职责:
  │   ├─ DOWNLOAD_FILE_REQ: 下载文件请求
  │   ├─ DOWNLOAD_FILE_BEGTIN: 客户端就绪
  │   └─ DOWNLOAD_SLICE_RES: 发送文件片

  ├─ MSG_SAVE_CONFIG_REQ/RES (9/10): 保存配置
  ├─ MSG_LOAD_CONFIG_REQ/RES (11/12): 加载配置
  ├─ MSG_LOAD_ALL_CONFIG_REQ/RES (13/14): 配置列表

九、消息通信流程
--------------------------------------------------------------------------------

9.1 服务启动流程
  ┌──────────┐   ①注册     ┌──────────┐   ②获取配置  ┌──────────┐
  │ 微服务    │──────────→ │ 注册中心  │──────────→  │ 配置中心  │
  │ (Auth/等) │←────────── │ (port:20018)│           │ (port:20019)│
  └──────────┘   响应       └──────────┘             └──────────┘

9.2 客户端请求流程
  桌面客户端                   网关                       微服务
  ┌──────┐   ①登录请求      ┌──────┐   ②鉴权proxy    ┌──────────┐
  │      │────────────────→│      │───────────────→  │ Auth     │
  │      │←────────────────│      │←───────────────  │ (port:20020)│
  │      │   登录响应        │      │                 └──────────┘
  │      │   ③目录请求      │      │   ④路由转发     ┌──────────┐
  │      │────────────────→│      │───────────────→  │ Dir      │
  │      │←────────────────│      │←───────────────  │ (port:20300)│
  │      │   目录响应        │      │                 └──────────┘
  │      │   ⑤上传请求      │      │   ⑥路由转发     ┌──────────┐
  │      │────────────────→│      │───────────────→  │ Upload   │
  │      │←────────────────│      │←───────────────  │ (port:20100)│
  │      │   上传响应        │      │                 └──────────┘
  └──────┘                 └──────┘

9.3 网关路由逻辑
  XRouterHandle::ReadCB() 收到客户端消息 →
    ① 验证 Token (XAuthProxy::CheckToken)
    ② 按 head->service_name 查找 XServiceProxy
    ③ 轮询选择可用后端服务
    ④ XServiceProxyClient::SendMsg(head, msg, router_handle)
    ⑤ 后端返回后通过 callback_task_ 回传给 XRouterHandle
    ⑥ XRouterHandle::SendMsg() 回复客户端

十一、文件存储说明
--------------------------------------------------------------------------------
  ├─ 用户文件通过上传/下载服务以文件片形式传输
  ├─ 支持 AES 加密存储 (用户输入密码)
  ├─ 支持断点续传 (offset 偏移量)
  ├─ 支持 MD5 校验 (秒传判断)
  ├─ 每个上传/下载连接处理单个文件
  ├─ 服务端以 ofstream 直接写入本地文件系统
  └─ 目录服务管理文件元数据和目录结构

  ├─ MySQL Connector/C: 数据库
  ├─ Qt6: 桌面 GUI
