一、环境要求
================================================================================

1.1 开发工具
  - Visual Studio 2022 Professional/Community (v143 工具集)
    - 需要安装 "使用 C++ 的桌面开发" 工作负载
    - 若编译 Qt GUI 项目还需要 Qt VS Tools 扩展
  - Qt 6.11.0 MSVC 2022 64-bit (位于 D:\Code\qt\6.11.0\msvc2022_64)
  - Git (用于版本管理)
  - Python 3.x (可选, 用于辅助脚本)

1.2 第三方依赖库 (已预编译, 位于 D:\Code\cpp\xms\)
  ├─ libevent          — 异步网络框架 (libevent.lib, libevent_core.lib)
  ├─ Google Protobuf   — 数据序列化 (libprotobuf.lib / libprotobufd.lib)
  ├─ OpenSSL           — SSL/TLS 加密通信 (libssl.lib, libcrypto.lib)
  ├─ MySQL Connector/C — 数据库连接 (libmysql.lib)
  ├─ zlib              — 压缩 (zlib.lib)
  ├─ Abseil            — C++ 基础库 (absl_*.lib, Protobuf 依赖)
  └─ Qt 6.11.0         — GUI 框架 (仅 config_gui, xms_disk_client_gui)

1.3 MySQL 数据库
  - MySQL Server 5.7+ (推荐 8.0)
  - 需要创建三个数据库:
    ├─ xms_config    — 配置中心数据
    ├─ xms_auth      — 用户鉴权数据
    └─ xms_log       — 日志数据

1.4 hosts 文件配置
  文件位置: C:\Windows\System32\drivers\etc\hosts
  需要添加以下记录 (根据实际部署IP修改):
  ┌──────────────────────────────────────────────────────────────┐
  │ # XMS 微服务 (部署服务器IP, 假设单机部署 127.0.0.1)         │
  │ 127.0.0.1 xms_gateway_server                                │
  │ 127.0.0.1 xms_register_server                               │
  └──────────────────────────────────────────────────────────────┘
  说明: 代码中通过 XGetHostByName() 函数读取 hosts 文件解析域名

2.3 使用 Visual Studio 构建
  A) 分别打开每个 .sln 文件, 按顺序构建
  B) 或使用单独项目 .vcxproj 构建:
     msbuild /p:Configuration=Debug /p:Platform=Win32 LXMysql\LXMysql.vcxproj
     msbuild /p:Configuration=Debug /p:Platform=Win32 xplatform\xplatfrom.vcxproj

2.4 使用命令行一键构建 (Developer Command Prompt)
  需要在 "VS 2022 Developer Command Prompt" 或已执行 vcvarsall.bat
  的环境中执行:

  ┌──────────────────────────────────────────────────────────────┐
  │ # 设置环境变量                                                │
  │ set XMS_ROOT=D:\Code\cpp\C++微服务架构及安全云盘项目\xms0.1.1 │
  │ set BUILD_CFG=Debug                                           │
  │ set BUILD_PLAT=Win32                                          │
  │                                                               │
  │ # 1. 构建 LXMysql                                             │
  │ msbuild %XMS_ROOT%\LXMysql\LXMysql.vcxproj                    │
  │   /p:Configuration=%BUILD_CFG% /p:Platform=%BUILD_PLAT%       │
  │                                                               │
  │ # 2. 构建 xplatform                                           │
  │ msbuild %XMS_ROOT%\xplatform\xplatfrom.vcxproj                │
  │   /p:Configuration=%BUILD_CFG% /p:Platform=%BUILD_PLAT%       │
  │                                                               │
  │ # 3. 构建所有服务 (按依赖顺序)                                 │
  │ for %%p in (                                                  │
  │   register_server config_server xauth_server xlog_server      │
  │   xms_gateway xms_dir_service xms_upload_service              │
  │   xms_download_service config_client register_client          │
  │ ) do (                                                        │
  │   msbuild %XMS_ROOT%\%%p\%%p.vcxproj                          │
  │     /p:Configuration=%BUILD_CFG% /p:Platform=%BUILD_PLAT%     │
  │ )                                                             │
  │                                                               │
  │ # 4. 构建 Qt GUI 项目 (需要 Qt VS Tools 或 CMake)             │
  │ msbuild %XMS_ROOT%\xms_disk_client_gui\xms_disk_client_gui.vcxproj │
  │   /p:Configuration=%BUILD_CFG% /p:Platform=%BUILD_PLAT%       │
  └──────────────────────────────────────────────────────────────┘

五、数据库初始化
================================================================================

5.1 安装 MySQL Server
  下载: https://dev.mysql.com/downloads/mysql/
  版本: MySQL 8.0 或 5.7
  安装后确保 MySQL 服务正在运行

5.2 创建数据库和用户
  ┌──────────────────────────────────────────────────────────────┐
  │ -- 登录 MySQL                                                │
  │ mysql -u root -p                                             │
  │                                                              │
  │ -- 创建数据库                                                │
  │ CREATE DATABASE IF NOT EXISTS xms_config DEFAULT CHARSET utf8;│
  │ CREATE DATABASE IF NOT EXISTS xms_auth DEFAULT CHARSET utf8;  │
  │ CREATE DATABASE IF NOT EXISTS xms_log DEFAULT CHARSET utf8;   │
  │                                                              │
  │ -- 创建专用用户 (可选)                                       │
  │ CREATE USER 'xms'@'localhost' IDENTIFIED BY '123456';        │
  │ GRANT ALL ON xms_config.* TO 'xms'@'localhost';              │
  │ GRANT ALL ON xms_auth.* TO 'xms'@'localhost';                │
  │ GRANT ALL ON xms_log.* TO 'xms'@'localhost';                 │
  │ FLUSH PRIVILEGES;                                            │
  └──────────────────────────────────────────────────────────────┘

5.3 数据库初始化脚本 (install_db.bat)
  各服务在首次启动时, 如果检测到表不存在会自动创建:
  ┌──────────────────────────────────────────────────────────────┐
  │ @echo off                                                    │
  │ echo 初始化配置中心数据库...                                  │
  │ start /wait config_server.exe install                        │
  │ echo 初始化鉴权服务数据库...                                  │
  │ start /wait xauth_server.exe install                         │
  │ echo 初始化日志服务数据库...                                  │
  │ start /wait xlog_server.exe install                          │
  │ echo 数据库初始化完成!                                       │
  └──────────────────────────────────────────────────────────────┘

  说明: 每个服务都包含 DAO::Install() 方法自动创建所需的表结构。
  在 main() 中首次调用 Init() 后即调用 Install()。

六、配置说明
================================================================================

6.1 数据库连接配置（位于相关 DAO 类）
  ├─ config_dao:   默认连接 localhost:3306, root, 123456, xms_config
  ├─ xauth_dao:    默认连接 localhost:3306, root, 123456, xms_auth
  └─ xlog_dao:     默认连接 localhost:3306, root, 123456, xms_log

  若需修改,需在对应 DAO 类的 Init() 方法中修改连接参数。

6.2 服务端口配置
  服务端口通过命令行参数传递: <exe_name> [port] [register_ip] [register_port]
  ┌──────────────────────────────────────────────────────────────┐
  │ # 示例: 修改网关端口和注册中心地址                            │
  │ xms_gateway.exe 20010 192.168.1.10 20018                     │
  │                                                              │
  │ # 示例: 修改鉴权服务端口和注册中心地址                        │
  │ xauth_server.exe 20020 192.168.1.10 20018                    │
  └──────────────────────────────────────────────────────────────┘

  默认端口定义在 xplatform/xmsg.h 中:
  ├─ API_GATEWAY_PORT = 20010
  ├─ REGISTER_PORT    = 20018
  ├─ CONFIG_PORT      = 20019
  ├─ AUTH_PORT        = 20020
  ├─ XLOG_PORT        = 20030
  ├─ UPLOAD_PORT      = 20100
  ├─ DOWNLOAD_PORT    = 20200
  └─ DIR_PORT         = 20300

6.3 主机名配置
  主机名定义在 xplatform/xmsg.h 中:
  ├─ API_GATEWAY_SERVER_NAME  = "xms_gateway_server"
  └─ API_REGISTER_SERVER_NAME = "xms_register_server"

  需要映射到 hosts 文件中。

================================================================================
七、常见部署问题排查
================================================================================

7.1 启动后服务闪退
  可能原因及解决方案:
  ├─ DLL 缺失 → 将所有依赖 DLL 放到 exe 同目录或系统 PATH 中
  ├─ 端口被占用 → 使用 netstat -ano | findstr 20018 检查端口
  ├─ MySQL 连接失败 → 检查 MySQL 服务是否启动, 连接参数是否正确
  └─ hosts 解析失败 → 检查 hosts 文件是否正确配置

7.2 服务连接失败
  ├─ 确保注册中心先启动, 其他服务后启动
  ├─ 检查防火墙是否放行对应端口
  ├─ 检查 hosts 文件中的域名解析
  └─ 查看各服务控制台输出的诊断信息

7.3 MySQL 连接问题
  ├─ 确认 MySQL 服务运行: net start MySQL80
  ├─ 确认用户权限: mysql -u root -p -e "SHOW DATABASES;"
  └─ 检查 LXMysql Init() 中的连接参数

7.4 编译错误
  ├─ LNK1104: 找不到 .lib → 确保依赖库先构建完成
  ├─ 找不到 include 文件 → 确保目录链接 include/ → xms/include 有效
  ├─ Qt 相关错误 → 确保 Qt6 目录配置正确, Qt VS Tools 已安装
  └─ /utf-8 编译警告 → 已在所有 .vcxproj 中添加该选项
